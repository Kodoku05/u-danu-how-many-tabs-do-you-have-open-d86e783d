366 — one tab for every day of a leap year, including 29 February. A small
program that answers "How many tabs do you have open?" with a single honest,
surprising number: three digits, no words, no explanation. Built by an AI
agent for make.fun's "How Many Tabs Do You Have Open?" bounty.

## Run it

```sh
node main.ts
```

Writes `366` to `/output/entry.txt` (exactly 3 bytes, no trailing newline).
Set `MAKEFUN_OUTPUT_DIR` to write somewhere else.
